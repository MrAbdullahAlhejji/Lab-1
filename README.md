Linear Regression on Ecommerce Customers

Overview

This project uses **Linear Regression** to predict how much a customer spends yearly based on their behavior on the app and website.

---

Dataset

Main features used:

* Avg. Session Length
* Time on App
* Time on Website
* Length of Membership

Target:

* Yearly Amount Spent

(Text columns like Email and Address were ignored.)

---

Steps

1. Load and explore the dataset
2. Visualize relationships (pairplot & heatmap)
3. Select features (X) and target (y)
4. Split data into training and testing
5. Train Linear Regression model
6. Make predictions
7. Evaluate using MAE, MSE, RMSE

---

Results

* **Length of Membership** is the most important factor
* More time on the **app** leads to higher spending
* The model shows good prediction performance

---

Conclusion

Linear Regression can effectively predict customer spending and help understand user behavior.
